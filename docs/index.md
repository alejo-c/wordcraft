# Documentation index

## Format

- Symbol entries name a file and definition, describe its concern, and list Uses: and Used by: relationships.
- Existing domain documentation is indexed by architecture.md and AGENTS.md.

## Symbol map

- Mardok engine commands, native process integration and ribbon/panel, docs/mardok-map.md.
- Mardok CLI constraints and integration decisions, docs/mardok.md.
- Project directory listing, docs/context/structure.md and docs/structure.md.
- Existing architecture and crate layers outside this integration, docs/architecture.md.
- Existing source outside this map must be searched before creating symbols.

## File index

- architecture.md: workspace layers, data flow and Helix modal editing symbols.
- spotlight.md: native paragraph-style badges, Styles pane color indicators and spotlight preferences.
- TODO.md: pending work and verification commands.
- PROGRESS.md: completed work.
- structure.md: workspace directories, spotlight and Helix files.
